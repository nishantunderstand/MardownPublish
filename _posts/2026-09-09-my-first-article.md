# My First Markdown Article

This is my first article written in **Markdown** and published through GitHub Pages.

## Why Markdown?

Markdown makes it simple to write technical articles while keeping the original content as plain text.

For example:

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

You can also write equations:

$E = mc^2$

## Conclusion

My articles can now be stored, version-controlled, and published from GitHub.
