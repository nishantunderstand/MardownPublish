Why it is called Red-Black Tree ?

Begineer Level : Self Balancing Binary Search Tree

A Red-Black Tree has several rules. The important ones are:

1. Every node is either Red or Black.
2. Root is Black.
3. `null`/NIL leaves are considered Black.
4. A Red node cannot have a Red child.
```
        20(B)
       /    \
    10(R)   30(R)
```
