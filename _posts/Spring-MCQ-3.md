**Q1.** Which of the following statements about **Dependency Injection (DI)** in Spring is true?
A) DI is used to create objects manually inside your code.
B) DI allows the Spring container to manage object creation and dependencies.
C) DI is only applicable for primitive data types.
D) DI and IoC are completely unrelated concepts.

B

**Q2.** In Spring, which of the following is **NOT a type of Dependency Injection**?
A) Constructor Injection
B) Setter Injection
C) Field Injection
D) Method Overloading Injection

D

**Q3.** Which Spring container **loads bean definitions lazily** by default?
A) ApplicationContext
B) BeanFactory
C) WebApplicationContext
D) SpringBootApplication

B

**Q4.** Which annotation is used to **autowire a bean by type** in Spring?
A) @Bean
B) @Autowired
C) @Component
D) @Qualifier

B

**Q5.** What is the **default scope of a Spring bean**?
A) Singleton
B) Prototype
C) Request
D) Session

A

**Q6.** Which collection types can Spring inject into a bean?
A) List
B) Set
C) Map
D) All of the above

D

**Q7.** Which of the following is **true about @Value annotation**?
A) It can inject values from properties files.
B) It can only inject numeric values.
C) It replaces @Autowired for injecting beans.
D) It is used to define a bean scope.

A

**Q8.** Which of the following is a **module of Spring Framework**?
A) Spring AOP
B) Spring JDBC
C) Spring MVC
D) All of the above

D

**Q9.** What is the **difference between ApplicationContext and BeanFactory**?
A) BeanFactory supports internationalization, ApplicationContext doesn’t
B) ApplicationContext eagerly loads singleton beans, BeanFactory lazy loads
C) BeanFactory can inject dependencies, ApplicationContext cannot
D) There is no difference

B

**Q10.** Which is the **correct order to inject collection types** into a Spring bean?
A) Properties → List → Set → Map
B) List → Set → Map → Properties
C) Set → Map → List → Properties
D) Any order, Spring handles it automatically

D
